# MEOW / ROOFTOP

Interactive Three.js rooftop concert. Orange cat DJ, animated crowd, LED stage, neon dancefloor, lounge, bar and instanced city windows.

## Run
Serve the repository with any static HTTP server, for example `python -m http.server 8000`, then open http://localhost:8000. Internet is required for the pinned Three.js CDN modules.

## Controls
Drag to orbit, scroll to zoom. Camera buttons select smooth cinematic views. Light switches palettes. Sound starts an original procedural 128 BPM loop after a user gesture. H hides the interface. Quality switches rendering resolution and bloom.

## Hosting
The root index.html is ready for static hosting. For GitHub Pages, enable Settings > Pages > Deploy from a branch > main / root. Repository publication alone does not enable Pages.

## Verification
Authored without browser rendering access; no claim of visual or cross-browser testing. No external models, textures, audio files or API keys. WebGL2 and a modern browser are required.
